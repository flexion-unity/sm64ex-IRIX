# sm64ex-IRIX
Fork of [sm64pc/sm64ex](https://github.com/sm64pc/sm64ex) which is a fork of [sm64-port/sm64-port](https://github.com/sm64-port/sm64-port)

This fork is intended for BUILD and RUN on SiliconGraphics **IRIX** (big endian MIPS).


## Prerequisites

* IRIX 6.5.x
* [SGUG-RSE](https://github.com/sgidevnet/sgug-rse/) environment for gcc, SDL2, etc
* A legally acquired sm64 ROM


## Building

For building instructions, please refer to the [wiki](https://github.com/sm64pc/sm64ex/wiki).

Make sure you are in 'sgugshell' before you run 'make'.


## Approximate build duration

* SiliconGraphics O2 400MHz: ~1 hour 12 minutes
* SiliconGraphics Octane 2x 300MHz: ~40 minutes
* SiliconGraphics Origin300 16x600MHz (NUMALink): ~5 minutes
